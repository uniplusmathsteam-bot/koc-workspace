Binary Numbers — Step-by-Step

Short division Marbles
Denary → Binary

Convert a denary number into a binary number by short division. Keep dividing by 2 and record every remainder. Then read the last quotient together with the remainders from the bottom to the top.

  1. The two rules

    1. Keep dividing by 2 until the quotient is less than 2. Write down the remainder at every step (it is always 0 or 1).
    2. The binary number is the last quotient followed by the remainders you already wrote, read in this order: bottom → top.

    The first remainder you write is the last binary digit (the 20 place). The last quotient at the bottom is the first binary digit.

  2. Example 1 — divide 38 by 2, one row at a time

    Even numbers give remainder 0. Odd numbers give remainder 1.

    Click “Next row” after each division. Then click each “?” to reveal that remainder.

  3. Example 1 — read from the bottom

    Do not read the remainders from the top. Start at the last quotient on the last line, then walk up the remainder column.

    Click “Read next digit” to collect the bits from bottom to top.

    ∴ 3810 = 1001102

    Check: 1×32 + 0×16 + 0×8 + 1×4 + 1×2 + 0×1 = 32 + 4 + 2 = 38.

  4. Example 2 — divide 26 by 2

    Same process: next row, then click each remainder.

  5. Example 2 — read from the bottom

    Click “Read next digit”. The arrow on the right shows the reading direction.

    ∴ 2610 = 110102

    Check: 1×16 + 1×8 + 0×4 + 1×2 + 0×1 = 16 + 8 + 2 = 26.

  6. The common mistake

    Someone reads 38’s remainders from the top. Which binary number do they get, and which one is correct?

    Reading top → bottom gives 0110012 = 25, which is not 38. Always start at the bottom.

Question 55

David and Alice have some marbles. The number of marbles that David has is 8 times that of Alice. The total number of their marbles can be represented by a binary number such that each of its digits is 1. Find the least possible number of marbles that David has.

  1. Introduce a variable

    Alice has the smaller amount, so let her amount be the unknown.

    Let Alice have n marbles.
    Then David has 8n marbles.

  2. Find the total

    Fill in the box, then press Enter.

    Total = n + 8n = n

    Key fact: n is a whole number, so the total must be a multiple of 9.

  3. List binary numbers made only of 1s

    The total is a binary number where every digit is 1, so it can be 12, 112, 1112, 11112, …

    Click each "?" to show its denary value one at a time. Then click "Check" to test whether it is a multiple of 9.

    Pattern: each new value is (previous × 2) + 1. A string of k ones equals 2k − 1.

    Which is the smallest possible total of marbles?

    From the table, 63 = 1111112 is the smallest number that is all 1s in binary and a multiple of 9.
